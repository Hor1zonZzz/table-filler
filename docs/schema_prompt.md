# VL Agent - Schema配置阶段提示词

## 用户提示词（复制给用户）

```
请帮我配置供应商合同数据提取的Schema。

背景：
- 目标文档：供应商合同PDF（扫描件）
- 文档特点：20-40页，包含合同条款、采购清单、乙方信息等
- 提取目标：乙方基本信息、合同基本信息、采购内容明细

需要提取的字段：
1. 合同名称 - 合同的完整名称
2. 签订日期 - 合同签署日期（YYYY-MM-DD格式）
3. 合同金额 - 合同总金额（数字）
4. 合同类型 - 三选一：硬件设备类、服务类、办公物资类
5. 乙方名称 - 供应商公司名称
6. 乙方统一社会信用代码 - 18位社会信用代码
7. 乙方注册地址 - 企业注册地址
8. 乙方办公地址 - 实际办公地址（可选）
9. 乙方开户银行 - 银行全称（如"中国工商银行北京分行"）
10. 乙方银行账号 - 银行账户号码
11. 乙方对接人姓名 - 供应商联系人姓名
12. 采购内容 - 采购清单，需提取：产品名称、规格型号、技术参数、计量单位、购买数量、采购单价

请帮我配置这些字段，并确认Schema后开始提取。
```
